# 大厦形状：OSM 预设与调整工具

2026-10-09 加入。决定：新增大厦预设套用地图底图（OpenStreetMap，经 OpenFreeMap）上的建筑轮廓；不准确时，由同事在地图上用 2D 工具调整。

## 自动配对（导入时）

- 只处理没有形状的大厦；已有形状的不会被改。
- 按坐标下载底图同一来源的地图资料块（z14），找包住坐标的建筑。OSM 常同时画整幢建筑及其部分（例如平台上的塔楼），取整幢；若只有超过 1,500 m² 的大块（多半是连在一起的一排楼），取较小的部分并提示检查。
- 坐标不在任何建筑内时，取 15 米内最近的一幢并提示检查；再远则不猜，暂用预设方块并说明原因。
- 结果列在导入核对页「地圖形狀」，确认合并才写入。形状记录来源（`footprintSource`：OSM 编号、配对方式、时间）。
- 网络失败不会阻止导入，只会退回预设方块并写明原因。

## 在地图上新增大厦

2026-10-10 加入，不用经 Excel。

- 总览时（未选大厦），相机工具列下方的「＋」按钮。地图转为俯视，点一下大厦位置，系统按同一套规则配对 OSM 轮廓并即时显示；点别处可重选，点到已在名单的大厦会提示，Esc 取消。
- 填大厦名称、地址（必填）；大厦编号预填下一个未用的 `SYP-001` 式编号，可改；楼层及单位可留空，写法与 Excel「樓層單位摘要」相同（由最低一层开始，一行一层），读不懂整格不收。
- 坐标取轮廓中心；找不到轮廓时取点击位置并用预设方块。新大厦与 Excel 新增的一样，导出时写入「大廈總表」及「關聯封存」。

## 调整工具（地图上）

- 选中大厦后，相机工具列下方的「調整大廈形狀」按钮。进入后地图转为俯视并锁定倾角，楼层叠层暂时隐藏；离开后回到原本视角。
- 拖动边：平行移动，相邻两边保持方向自动伸缩；按住 Alt 可自由移动整条边。拖动顶点：只移动该点。点边中间的小圆点：加顶点。选中顶点按 Delete：删除（至少保留 3 个）。⌘Z：复原。
- 显示每条边长度、面积及顶点数。有交叉边、面积少于 10 m² 或顶点重叠时不能保存。
- 「用地圖形狀」重新取得 OSM 轮廓。保存时以新形状的中心更新坐标，并记录为 `manual`（操作人、时间）。
- 只改地图上的形状；到访记录挂在大厦／楼层／单位编号上，不受影响。
