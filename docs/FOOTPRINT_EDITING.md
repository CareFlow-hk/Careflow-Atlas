# 大廈形狀：OSM 預設與調整工具

2026-10-09 加入。決定：新增大廈預設套用地圖底圖（OpenStreetMap，經 OpenFreeMap）上的建築輪廓；不準確時，由同事在地圖上用 2D 工具調整。

## 自動配對（匯入時）

- 只處理沒有形狀的大廈；已有形狀的不會被改。
- 按座標下載底圖同一來源的地圖資料塊（z14），找包住座標的建築。OSM 常同時畫整幢建築及其部分（例如平台上的塔樓），取整幢；若只有超過 1,500 m² 的大塊（多半是連在一起的一排樓），取較小的部分並提示檢查。
- 座標不在任何建築內時，取 15 米內最近的一幢並提示檢查；再遠則不猜，暫用預設方塊並說明原因。
- 結果列在匯入核對頁「地圖形狀」，確認合併才寫入。形狀記錄來源（`footprintSource`：OSM 編號、配對方式、時間）。
- 網絡失敗不會阻止匯入，只會退回預設方塊並寫明原因。

## 調整工具（地圖上）

- 選中大廈後，相機工具列下方的「調整大廈形狀」按鈕。進入後地圖轉為俯視並鎖定傾角，樓層疊層暫時隱藏；離開後回到原本視角。
- 拖動邊：平行移動，相鄰兩邊保持方向自動伸縮；按住 Alt 可自由移動整條邊。拖動頂點：只移動該點。點邊中間的小圓點：加頂點。選中頂點按 Delete：刪除（至少保留 3 個）。⌘Z：復原。
- 顯示每條邊長度、面積及頂點數。有交叉邊、面積少於 10 m² 或頂點重疊時不能儲存。
- 「用地圖形狀」重新取得 OSM 輪廓。儲存時以新形狀的中心更新座標，並記錄為 `manual`（操作人、時間）。
- 只改地圖上的形狀；到訪記錄掛在大廈／樓層／單位編號上，不受影響。

## 未做

- 吸附到底圖建築邊或直角。
- 手機觸控編輯。
- 跨越地圖資料塊邊界的建築（輪廓會被裁切；西營盤示範範圍在同一塊內）。
- 預設方塊仍會隱藏與其外框重疊的底圖建築。
