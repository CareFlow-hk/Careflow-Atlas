# 纸本与 Excel 回录工作流

## 依据与边界

2026-09-11 依据 `CareFlow_洗楼_Master资料包_2026-09-10.zip` 的 `01_MASTER_CONTEXT.md` §4.4–5（S05、S25）及 `02_MVP_REQUIREMENTS.md`：外展按大厦使用纸本，回中心后整理个人表（一人一行）及大厦表（一厦一行）。原机构的确切栏名、唯一键、颜色规则、公式及核心原表仍未取得。资料包的三份 JSON 是候选视图；「五寶.xls」属相邻活动／财务流程，不能当作洗楼原表。

因此本次提供的是可用于验证流程的 mock 范本，不宣称相容未取得的机构原档。全部内容为合成资料；此原型仍只接受合成资料。

## 操作

1. 进入侧栏「紙本與 Excel」，外出前选大厦，打印 A4 大厦纸本。填日期、工作员、外出／纸本编号，按行记录。未知时间可空白。
2. 回中心「匯出目前 Excel」，在「紙本回錄」新行补录。新行没有记录编号时，以纸本编号、行号、大厦编号产生稳定识别码。不要改已有历史；更正以新行追加。
3. 选取回录档，检查新增明细、总数、重复与冲突，再确认合并。出错时整份不套用；会列出工作表、行、字段。删除 Excel 行不删除既有记录。
4. 查看「待跟進」。结案时在新的回录行填原始跟进的「結束跟進編號」及相同位置，写下结果；保留原始行。再次导出会计入新结果。

`public/demo/careflow-paper-excel-mock.xlsx` 为排版范本，带下拉选项、文字电话栏、日期格式和冻结栏列。工作台导出的现况档保留相同六页和资料格式；浏览器导出使用 SheetJS，排版较简洁。

## 工作表

| 工作表 | 用途 |
| --- | --- |
| 使用说明 | 版本、合成标记、填写原则、来源边界 |
| 大厦总表 | 一厦一行；可修改名称、地址；楼层与覆盖为计算摘要 |
| 个人名册 | 一人一行；名称、文字电话、住址原文、接触备注；会员与家庭仅供参考 |
| 纸本回录 | 每处每次到访一行；纸本来源、位置、覆盖、接触、判断、原话及跟进 |
| 待跟进 | 从历史计算的开放事项；类别、行动、负责人、确定日期及未确认时间原话 |
| 关联封存 | 完整合成快照，分段保存家庭、会员、居住、位置与历史关联。保留整页，不在此回录 |

只填日期不会产生推测时刻；已知时间以香港时区处理。居民的「翌日」「明年二月」放在时间原话栏，不能直接填确定日期。电话必须是文字，遇数字电话会要求核对，以免丢失前导零。公式、未知非空栏、未知工作表不会被静默忽略。

## 合并规则

- 精确编号比对，不按姓名、电话、同址合并人员。
- 全部集合按编号取联集，旧档不能删除较新的本机行。
- 既有观察不可改写。同纸本同一行重复导入可辨识；档名／导入时间改变不产生新事件。
- 大厦／个人修改依导出时快照比对；两边都改了同一笔时报冲突，重新导出后整理。
- 按确认时重新读取本机资料并再次验证，再一次写入。读取、格式或保存失败不替换本机记录。
- 旧版英文 demo Excel 仍可导入，使用保守合并；相同编号的不同内容不自动覆盖。
- 未有楼层的大厦（新增或从未宣告楼层）可在「大廈總表」的「樓層單位摘要」宣告楼层及单位：一行一层，由最低一层开始，写成「1 樓：1樓 A室、1樓 B室」，与导出格式相同。导入核对页列出「新建樓層結構」，确认合并后才写入；同一文件的纸本回录可以直接使用这些单位。写法读不懂、楼层或单位重复、编号已被使用，或有数字的楼层由高至低排列，都会报错并指出行号，不会静默略过。
- 已有楼层的大厦仍不能在此修改楼层或单位，修改只会提示「不會套用」，以免改动已有历史的位置。新增行填了覆盖概况、最近到访等计算栏，也会提示不会套用。
- 修正前曾以「無樓層」合并的大厦，可再次导入同一文件补上楼层；只有楼层宣告不同、其他字段一致时才会更新，否则仍报冲突。
- 新大厦没有占地轮廓，地图以坐标为中心画预设方块。新个人不会自动建立家庭、居住或会员关联；这些关系仍需后续明确映射流程。

## 新对话带来的产品调整

提供四类轻量跟进：一般、住屋变动、健康关怀、服务邀约，补充负责人及时间原话。三条 mock 记录分别示范收房安排待核实、脚部不适／步行困难的关怀安排、介绍服务后邀请到中心。

这段转录噪音多，较可靠的方向是外展接触与服务跟进。没有采用「承接間隔房工程」的摘要，也未推定痛风、法规适用、确定搬迁期限或已成功邀约／入会。手机现场记录、语音上传及自动医疗／法律判定不在本次流程。

## 审查修复后的更正和导入规则

- 在新行填写「更正原記錄編號」。连续更正指向前一版本；更正分叉会阻止整个合并，不能靠再追加一行掩盖分叉。
- 修改跟进行动或结案引用时必须填写「更正原因」。已结案任务的普通更正不会重新打开任务；撤销结案必须显式更正结案事件并写明原因。
- 同一文件内的更正引用在读完全部行后验证，排序和空白行不改变关系或实际行号。
- 字段映射目前只供预览。修改后旧的待导入数据失效，需要整理原文件再重新载入；推测格式不能直接写入。
- 两种 Excel 解析器都阻止未知数据被静默丢弃。旧英文格式保留原始数值精度；文件限 5 MB，每页限 5000 行、64 列。

## 导入提示的写法（2026-10-09）

- 每个问题分两部分：给中心同事看的说明（哪里错、怎样改），以及折叠的「技術資料」（代码、位置、原始值），方便我们排查。说明不出现内部编号或英文。
- 同一句提示出现在多行时合并成一项，列出行号范围；表头被改名时只报缺少的字段，不再逐行报错。
- 日期另外接受「2026/10/09」「2026.10.9」这类年份在前的写法；「9/10/2026」日月次序不明，仍然报错。楼层、单位先精确对应，对不上时才忽略大小写和空格，而且必须唯一。
- 空白工作区也可以开启「紙本與 Excel」，下载空白范本，只用机构自己的大厦。
