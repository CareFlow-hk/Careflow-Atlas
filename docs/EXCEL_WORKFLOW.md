# 紙本與 Excel 回錄工作流

## 依據與邊界

2026-09-11 依據 `CareFlow_洗楼_Master资料包_2026-09-10.zip` 的 `01_MASTER_CONTEXT.md` §4.4–5（S05、S25）及 `02_MVP_REQUIREMENTS.md`：外展按大廈使用紙本，回中心後整理個人表（一人一行）及大廈表（一廈一行）。原機構的確切欄名、唯一鍵、顏色規則、公式及核心原表仍未取得。資料包的三份 JSON 是候選視圖；「五寶.xls」屬相鄰活動／財務流程，不能當作洗樓原表。

因此本次提供的是可用於驗證流程的 mock 範本，不宣稱相容未取得的機構原檔。全部內容為合成資料；此原型仍只接受合成資料。

## 操作

1. 進入側欄「紙本與 Excel」，外出前選大廈，列印 A4 大廈紙本。填日期、工作員、外出／紙本編號，按行記錄。未知時間可空白。
2. 回中心「匯出目前 Excel」，在「紙本回錄」新行補錄。新行沒有記錄編號時，以紙本編號、行號、大廈編號產生穩定識別碼。不要改已有歷史；更正以新行追加。
3. 選取回錄檔，檢查新增明細、總數、重複與衝突，再確認合併。出錯時整份不套用；會列出工作表、行、欄位。刪除 Excel 行不刪除既有記錄。
4. 查看「待跟進」。結案時在新的回錄行填原始跟進的「結束跟進編號」及相同位置，寫下結果；保留原始行。再次匯出會計入新結果。

`public/demo/careflow-paper-excel-mock.xlsx` 為排版範本，帶下拉選項、文字電話欄、日期格式和凍結欄列。工作台匯出的現況檔保留相同六頁和資料格式；瀏覽器匯出使用 SheetJS，排版較簡潔。

## 工作表

| 工作表 | 用途 |
| --- | --- |
| 使用說明 | 版本、合成標記、填寫原則、來源邊界 |
| 大廈總表 | 一廈一行；可修改名稱、地址；樓層與覆蓋為計算摘要 |
| 個人名冊 | 一人一行；名稱、文字電話、住址原文、接觸備註；會員與家庭僅供參考 |
| 紙本回錄 | 每處每次到訪一行；紙本來源、位置、覆蓋、接觸、判斷、原話及跟進 |
| 待跟進 | 從歷史計算的開放事項；類別、行動、負責人、確定日期及未確認時間原話 |
| 關聯封存 | 完整合成快照，分段保存家庭、會員、居住、位置與歷史關聯。保留整頁，不在此回錄 |

只填日期不會產生推測時刻；已知時間以香港時區處理。居民的「翌日」「明年二月」放在時間原話欄，不能直接填確定日期。電話必須是文字，遇數字電話會要求核對，以免丟失前導零。公式、未知非空欄、未知工作表不會被靜默忽略。

## 合併規則

- 精確編號比對，不按姓名、電話、同址合併人員。
- 全部集合按編號取聯集，舊檔不能刪除較新的本機行。
- 既有觀察不可改寫。同紙本同一行重複匯入可辨識；檔名／匯入時間改變不產生新事件。
- 大廈／個人修改依匯出時快照比對；兩邊都改了同一筆時報衝突，重新匯出後整理。
- 按確認時重新讀取本機資料並再次驗證，再一次寫入。讀取、格式或儲存失敗不替換本機記錄。
- 舊版英文 demo Excel 仍可匯入，使用保守合併；相同編號的不同內容不自動覆蓋。
- 新大廈不會憑備註生成樓層／單位；新個人不會自動建立家庭、居住或會員關聯。這些結構仍需後續明確映射流程。

## 新對話帶來的產品調整

提供四類輕量跟進：一般、住屋變動、健康關懷、服務邀約，補充負責人及時間原話。三條 mock 記錄分別示範收房安排待核實、腳部不適／步行困難的關懷安排、介紹服務後邀請到中心。

這段轉錄噪音多，較可靠的方向是外展接觸與服務跟進。沒有採用「承接間隔房工程」的摘要，也未推定痛風、法規適用、確定搬遷期限或已成功邀約／入會。手機現場記錄、語音上傳及自動醫療／法律判定不在本次流程。

## 驗證

`src/data/workflowWorkbook.test.ts` 覆蓋六頁資料往返、styled mock 解析、紙本追溯、日期精度、Excel 1904 日期、電話、重复匯入、舊檔保留新資料、歷史保護、同步衝突及結案往返。既有 domain／repository／map 測試同時保留。瀏覽器另外檢查工作台、mock 核對及大廈紙本預覽；未將測試資料合併進使用者現有工作區。

## 审查修复后的更正和导入规则

- 在新行填写「更正原記錄編號」。连续更正指向前一版本；更正分叉会阻止整个合并，不能靠再追加一行掩盖分叉。
- 修改跟进行动或结案引用时必须填写「更正原因」。已结案任务的普通更正不会重新打开任务；撤销结案必须显式更正结案事件并写明原因。
- 同一文件内的更正引用在读完全部行后验证，排序和空白行不改变关系或实际行号。
- 字段映射目前只供预览。修改后旧的待导入数据失效，需要整理原文件再重新载入；推测格式不能直接写入。
- 两种 Excel 解析器都阻止未知数据被静默丢弃。旧英文格式保留原始数值精度；文件限 5 MB，每页限 5000 行、64 列。
